# SKILL — OPPORTUNITY ANALYSIS

Core Question:
"What public evidence suggests that a proprietary website could provide meaningful utility to this business?"

Inspect:
- digital activity (Instagram, Linktree, WhatsApp scheduling);
- commercial activity & physical structure;
- service catalog / specialties / exams / products;
- booking/appointments flow;
- repeated customer inquiries;
- fragmented information across social links;
- lack of own web presence for Google local search capture.

Output:
`classification` + `evidence` + `hypothesis` + `uncertainties` + `adversarial_audit`.

Do not predict purchase or guarantee financial results.
