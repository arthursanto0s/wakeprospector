# WORKFLOW — FIND LEADS

Input:
niche + location + quantity

Steps:
1. Parse request.
2. Discover candidate businesses.
3. Verify identity/location/category.
4. Check website status.
5. Exclude confirmed own websites from target queue.
6. Deduplicate.
7. Investigate responsible.
8. Investigate professional contact.
9. Analyze opportunity.
10. Build evidence-backed lead card.
11. Mark READY_FOR_REVIEW when sufficient.
12. Save all results and exclusions.

Output:
- requested quantity if feasible;
- list of qualified/review leads;
- uncertainty summary;
- research coverage notes.
