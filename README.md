# WAKE PROSPECTOR

## Agente interno de inteligência comercial da Wake Studio

O Wake Prospector é um sistema interno, operado pelo Google Antigravity, para descobrir, investigar, qualificar e preparar leads de empresas locais que podem ter oportunidade de presença web.

### Princípio central

O sistema não deve tratar "empresa sem site" como sinônimo de "bom lead".

O objetivo é produzir **oportunidades de prospecção explicáveis**, com evidências verificáveis, identificação do responsável quando possível e o melhor contato profissional publicamente associado.

### V1

A V1 é deliberadamente enxuta:

1. Descobrir empresas por nicho + localização.
2. Confirmar identidade e localização.
3. Verificar a existência de site próprio.
4. Investigar responsável/proprietário/administração.
5. Procurar o melhor telefone profissional associado ao responsável.
6. Analisar sinais públicos de oportunidade para um site.
7. Classificar a oportunidade sem falsa precisão.
8. Criar ficha e mensagem inicial.
9. Deixar o envio do WhatsApp sob controle humano.
10. Registrar respostas e permitir análise posterior.

### Regra de ouro

**Antigravity é o cérebro operacional. Código é infraestrutura determinística. O humano decide quando abordar e assume leads interessados.**

Leia `docs/MASTER_CONTEXT.md` antes de qualquer implementação.
