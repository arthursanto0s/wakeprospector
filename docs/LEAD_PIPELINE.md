# LEAD PIPELINE

NEW
→ RESEARCHING
→ VERIFIED
→ NO_WEBSITE
→ RESPONSIBLE_FOUND
→ CONTACT_FOUND
→ QUALIFIED
→ READY_FOR_REVIEW
→ CONTACTED
→ WAITING_REPLY
→ RESPONDED

Branches:

RESPONDED → INTERESTED_HANDOFF
RESPONDED → NOT_INTERESTED
RESPONDED → NOT_RESPONSIBLE
RESPONDED → UNCERTAIN

Any stage may become DISCARDED with a mandatory reason.

## Status semantics

READY_FOR_REVIEW means:
- research complete enough;
- evidence recorded;
- recommended contact selected;
- opening message generated;
- human decision pending.

INTERESTED_HANDOFF means:
- lead expressed meaningful interest;
- automated assistance stops;
- user takes over.
